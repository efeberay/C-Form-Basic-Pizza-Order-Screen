C# Basic Pizza Order Screen
🇹🇷 Türkçe

Bu proje, C# Windows Forms kullanılarak hazırlanmış basit bir Pizza Sipariş Ekranı tasarımını içermektedir.

Projede yalnızca arayüz (UI) tasarımı yapılmıştır.
Herhangi bir hesaplama, sipariş işleme veya arka plan mantığı (business logic) bulunmamaktadır.

Amaç, temel WinForms kontrollerini (ComboBox, ListBox, RadioButton, CheckBox, TextBox, Button vb.) kullanarak basit bir form tasarımı oluşturmaktır.

🇬🇧 English

This project contains a simple Pizza Order Screen designed using C# Windows Forms.

Only the user interface (UI) design has been implemented.
There is no calculation logic, order processing, or backend functionality included.

The main purpose of this project is to demonstrate basic WinForms controls such as ComboBox, ListBox, RadioButton, CheckBox, TextBox, and Button.
